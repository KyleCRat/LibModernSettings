# WeakAuras texture artwork

These 31 TGA files are unchanged artwork from
[WeakAuras 5.20.7](https://github.com/WeakAuras/WeakAuras2/tree/5.20.7/WeakAuras/Media/Textures),
Git tree `ca81cc70dd3c7f3fcb98b0fcddb475b2366a4d82`.
Copyright belongs to the WeakAuras authors and contributors.

The artwork is distributed under the upstream **GNU General Public License,
version 2**, reproduced in [LICENSE](LICENSE). It is provided without warranty.
This third-party artwork is not covered by LibModernSettings' MIT license.

The files were copied from the locally installed WeakAuras package and every
Git blob hash was verified against that upstream release. No pixels, filenames
or dimensions were changed. The TGA files distributed upstream are included
here directly.

The bundled selection contains rings, circles, gradients, square borders,
triangles, targeting shapes and striped/rainbow bars. Blizzard alerts, sparks,
beams, runes and atlases are referenced from the game, not copied here.
Neither WeakAuras nor LibYvSkins is a runtime dependency.
